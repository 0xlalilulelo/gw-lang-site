Mission Briefing

Doc-ID: GW-DOC-001
Classified: PUBLIC
▶ TRANSMISSION OPEN FREQ: 140.85 // ENC: AES-256

GW is a systems programming language for the operators who actually ship — kernel hackers, game-engine engineers, embedded firmware teams, performance-critical infra. It fuses HolyC's single-pass interactive compilation philosophy with the modern systems toolkit defined by Zig, Odin, Jai, and Rust.

No headers. No preprocessor. Top-level statements execute. Bare strings print. The shell is the compiler. Allocators are explicit when you want them and ambient when you don't. Memory safety is a gradient — safe by default, naked when the kernel demands it.

Built for the hardware in front of you, cross-compiled to anything else. One binary. One ABI. Mission complete.

Capabilities

06 OF 06 ACTIVE
STATUS: NOMINAL
SYS-01 // CORE ●

Single-Pass Compilation

Direct-to-machine-code TPDE-style backend. Target throughput: 1M lines per second per core. The edit-build-run loop disappears.

▶ arsenal build --fast
SYS-02 // SAFETY ●

Memory Safety Gradient

Three tiers: safe (region-checked references), manual (opt-out borrow check), naked (full unsafe). Pick the right altitude.

▶ safe / manual / naked
SYS-03 // META ●

Comptime Engine

Run any GW code at compile time inside #virtuous blocks. Generate types, derive serializers, embed assets. One mechanism replaces macros, templates, and codegen.

▶ #virtuous { ... }
SYS-04 // DEPLOY ●

Cross-Compilation

Bundled libcs for musl, glibc, mingw-w64, Apple SDK, wasi-libc. Linux, macOS, Windows, FreeBSD, WASM, freestanding. Target triple is a flag.

▶ --target aarch64-macos
SYS-05 // ASYNC ●

Fox Tasks & Channels

M:N work-stealing scheduler. Lightweight fox tasks, typed bounded channels, structured concurrency via nursery blocks. io_uring/kqueue/IOCP under the hood.

▶ fox / nursery / await
SYS-06 // INTEROP ●

C ABI & FFI

Drop in any C header with --import-c. Bidirectional C ABI via cipher "C". No bindings file. Inline assembly with named-local visibility.

▶ extern cipher "C"
