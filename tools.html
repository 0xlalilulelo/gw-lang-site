First-class Tooling

The GW toolchain is batteries-included. Package management, formatting, linting, and language server support are built directly into the core binary. No third-party fragmentation.

Build & Package

gw pkg is the official package manager and build system. It resolves dependencies, downloads cryptographic hashes, and orchestrates parallel compilation automatically.

Read pkg Docs ▸
$ gw pkg build --release

[1/4] Fetching dependencies...
[2/4] Compiling stdlib [x86_64-linux]...
[3/4] Compiling main.gw...
[4/4] Linking target...

Mission complete in 0.42s.

Code Formatting

gw fmt enforces a strict, uncompromising code style. End the formatting debates before they begin, and ensure every codebase looks like it was written by the same operative.

Read fmt Specs ▸
$ gw fmt src/

Diffing src/main.gw:
- let x= 10;
+ let x = 10;

Formatted 14 files.

Interactive REPL

gw repl brings the speed of JIT compilation to your terminal. Test comptime expressions, prototype algorithms, and inspect types interactively without writing a main function.

Explore the REPL ▸
$ gw repl

GW REPL v1.0
> comptime { 2 * 21 }
42
> _
