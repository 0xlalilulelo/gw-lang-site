ABI Stability

During the 0.x release cycle, GW does not guarantee ABI stability for internal calls. Breaking changes to struct layouts and calling conventions are expected as the compiler matures.

ABI v1 will be frozen at the Phase 10 milestone. For interoperability before then, use the extern class and extern fn directives, which strictly follow the C ABI of the target platform.

LIR Representation

LIR (Low-level IR) is the final representation before machine code emission. It is target-shaped but architecture-agnostic until final selection.

  • Virtual Registers: Operands are VirtualReg IDs.
  • ABI Awareness: Function calls are laid out according to the platform's calling convention (System V, Microsoft x64, etc.).
  • Opcodes: Simple opcodes mirroring SelectionDAG with high-level intrinsics like gep, load, and atomic.

Linkage Rules

GW uses lld as its default linker across all platforms (ELF, Mach-O, COFF, WASM). This ensures a consistent linking experience regardless of the host environment.

Symbols are mangled by default to support frequencies and generics. Use #[export] to export symbols with C-style linkage for FFI.
