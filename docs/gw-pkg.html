Overview

The gw pkg package manager is built directly into the GW-CORE toolchain. It manages dependencies, version resolution, and package distribution for GW projects.

Following the "batteries included" philosophy, it supports Git repositories as first-class dependencies alongside a community-run registry.

MotherBase.gw

The MotherBase.gw file is the project manifest. It is written in GW source, allowing for flexible, programmatic configuration using #virtuous blocks.

#virtuous {
    package = "Operator-eater";
    version = "0.3.1";
    dependencies = .{
        "philosophers/net": .{ .version = "1.x" },
        "github.com/foxhound/decoy": .{ .git = "...", .rev = "..." },
    };
}

PubGrub Resolution

GW uses the PubGrub algorithm for dependency resolution. PubGrub is designed to provide clear, human-readable explanations when conflicts occur, making it easier to manage complex dependency graphs.

A MotherBase.lock file records the exact version and Blake3 hash of every resolved dependency to ensure reproducible builds.

Integrity & Security

Security is a core priority for the gw pkg manager:

  • Cryptographic Hashing: All packages are verified against hashes in the lockfile.
  • Signed Releases: Official registry packages are cryptographically signed.
  • Namespacing: Mandatory namespacing prevents dependency confusion attacks.
