Overview

Comptime is GW's superpower. It allows running arbitrary code during compilation to generate types, optimize data structures, and perform reflection without runtime cost.

The comptime engine is a high-performance stack VM operating on MIR, providing 10–50x speedups over traditional tree-walking interpreters.

Directives

  • #run expr: Evaluates an expression at comptime and replaces the site with the resulting constant.
  • #insert(s): Re-feeds a byte array to the lexer and parser at the call site for procedural code injection.
  • #virtuous { ... }: A block executed entirely at comptime; declarations within escape to the surrounding scope.
#virtuous {
    if (TARGET_ARCH == .x86_64) {
        const VECTOR_SIZE = 64;
    } else {
        const VECTOR_SIZE = 16;
    }
}

Reflection API

Types are first-class values at comptime. You can inspect class fields, attributes, and signatures using reflection intrinsics.

  • @repl(T): Returns TypeInfo for a type, mirroring the language's internal representation.
  • @field(v, "name"): Accesses a field by string name, resolved at compile time.
  • @call(f, args): Dynamically dispatches a function call with a tuple of arguments.

Sandboxing

To ensure build reliability and security, comptime evaluation is strictly sandboxed:

  • No I/O: Access to the filesystem or network is prohibited by default.
  • Resource Caps: 256 MiB memory limit and 10⁹ operation limit per invocation.
  • Determinism: Results are bit-for-bit reproducible; no access to non-deterministic primitives like Now() or Random().
