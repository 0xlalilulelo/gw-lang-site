Overview

The GW Language Server Protocol (LSP) server provides a modern IDE experience for GW developers. It is built directly into the arsenal toolchain, ensuring that your editor is always in sync with the compiler.

It uses an incremental parsing strategy via the CST (Concrete Syntax Tree) to provide instantaneous feedback as you type.

Features

  • Hover: Displays type information, documentation comments, and attributes.
  • Navigation: Goto-definition, find-references, and workspace-wide rename.
  • Diagnostics: Real-time errors and warnings from the type checker and borrow checker.
  • Inlay Hints: Shows inferred types for locals and monomorphized generic arguments.
  • Code Actions: Automatic quick-fixes suggested by the compiler.

Performance

LSP responsiveness is a top priority. The server utilizes several optimization techniques:

  • Incremental CST: Only re-parses affected token ranges on every keystroke.
  • Per-frequency Cache: Reuses resolved symbol information across sessions.
  • Parallel Analysis: Independent analysis of function bodies across multiple cores.

Supported Editors

Since the server follows the standard Language Server Protocol, it is compatible with most modern editors:

  • VS Code: Official extension available via the marketplace.
  • Neovim: Integration via nvim-lspconfig.
  • Emacs: Supported via lsp-mode or eglot.
  • Zed: Native integration with the arsenal binary.
