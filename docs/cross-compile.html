Overview

GW provides true cross-compilation out of the box. The toolchain bundles the necessary headers and runtime libraries to target multiple operating systems and architectures from a single host binary.

No separate "cross-compiler" installation is required; the arsenal binary itself is the only tool you need.

Bundled libc Matrix

GW bundles the source or headers for every supported libc implementation to ensure consistent cross-compilation behavior.

Supported Targets

The compiler supports a wide matrix of architectures and operating systems. You can view the full list by running arsenal targets.

  • Architectures: x86_64, aarch64, riscv64, wasm32.
  • Operating Systems: Linux, macOS, Windows, FreeBSD, WASI.

Usage Guide

To cross-compile, simply specify the target triple during build. For Linux glibc targets, you can also specify a minimum version to ensure compatibility with older distributions.

# Cross-compile to Linux aarch64
arsenal build --target aarch64-linux-musl

# Target an older glibc version for maximum compatibility
arsenal build --target x86_64-linux-gnu.2.17
