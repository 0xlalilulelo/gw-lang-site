Overview

The arsenal binary is the single entry point for the entire GW toolchain. It includes the compiler, package manager, formatter, documentation generator, and LSP server.

Every subcommand is designed to be fast and responsive, following the philosophy of "one tool for the job."

Build & Run

  • arsenal build [path]: Builds the project at the specified path (default is .).
  • arsenal run [path] -- [args]: Builds and executes the resulting binary.
  • arsenal test [filter]: Discovers and runs tests, with support for glob filtering.
  • arsenal bench [filter]: Runs benchmarks with statistical outlier removal.

Development Tools

  • arsenal fmt [path]: Formats files in place using the standard style guide.
  • arsenal doc [path]: Generates structured documentation (Markdown/HTML/JSON).
  • arsenal lsp: Starts the Language Server Protocol (LSP) server on stdio.
  • arsenal codec: Starts the interactive REPL environment.

Package Management

  • arsenal cipher add <pkg>: Adds a dependency to MotherBase.gw.
  • arsenal cipher install: Resolves and installs all dependencies.
  • arsenal cipher update: Updates dependencies to their latest compatible versions.
