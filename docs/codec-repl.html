Overview

The codec REPL is the GW compiler running in JIT mode. It provides an interactive environment for rapid prototyping and experimentation.

Each line is parsed and immediately compiled. Top-level declarations are added to the session, while expressions are wrapped in synthetic functions and invoked.

Session State

The REPL maintains a persistent session state that survives across command invocations:

  • Symbol Table: Tracks all defined variables and functions.
  • Type Table: Stores resolved type information for the session.
  • JIT Module: Manages the machine code regions in memory.
  • History: Persisted to ~/.arsenal/codec_history for continuity.

JIT Architecture

The JIT engine writes machine code directly to managed memory regions. It uses an incremental emission strategy where each new declaration produces a fresh function in a new page-aligned chunk.

This approach avoids complex garbage collection for stale code while maintaining low latency (sub-100ms) for typical REPL statements.

W^X Security

GW handles modern OS security requirements for JIT-ed code natively:

  • Apple Silicon: Uses MAP_JIT and pthread_jit_write_protect_np to toggle between writable and executable states.
  • Hardened Linux: Utilizes memfd_create with dual mappings (RW and RX) for hardened execution environments.
  • Windows: Implements VirtualProtect with PAGE_EXECUTE_READ and explicit instruction cache flushing.
